---
title: Back returns the caret to where you ⌘-clicked
kind: fix
area: app
---
After a ⌘-click to a definition, **⌃−** now puts the caret on the word you clicked, not where it was before you scrolled. Declined large-file opens and reopening the current file no longer leave empty stops, and a symbol with very many matches now resolves to the same definition every time.
