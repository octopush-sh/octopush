## Octopush 0.4.106

### Features

- **Claude Code says what it's waiting on** — In a Run terminal, Claude Code now tells Octopush when it is **waiting on permission** or **waiting on your input**. Mission Control shows it on the card and a notification names the workspace. Turn it off in Settings › General.

### Fixes

- **The session switcher opens ready to type** — The session switcher now puts the cursor in its search field however you open it: its icon, **⌘⌥K**, or **⌘D** from a terminal. In Talk, the terminal toggle has its own row and no longer crowds the first message.
