---
title: Talk no longer cuts a reply's first line at a URL
kind: fix
area: app
---
The serif first line of a Talk reply now ends only where the sentence does. A dot inside a URL,
inline code, a link, a version like `v0.4.141`, a number or a file name no longer splits it, and a
first sentence that carries a URL or a link stays in the body, whole and clickable.
