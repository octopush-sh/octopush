Everywhere a run is shown in miniature (Mission Control, the Companion, run history and crew cards
in Talk), the dot for a running stage is now verdigris with a faint halo instead of brass. Brass now
only marks a crew that is waiting on you, so busy crews and crews that need you no longer look alike.
