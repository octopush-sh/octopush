kind: improvement

highlight: true
steps:
  - open: settings/account
    target: settings-account-sync-history-status
    caption: Each Sync toggle that is on now says when it last sent, or that the last attempt failed.
    action: none
---
Under each Sync toggle that is on, Settings › Account now shows the last attempt: when it sent
and how many runs or items, or that it failed (with the HTTP status) and retries with the next
run. Only the time, outcome, count and status are kept on this Mac.
