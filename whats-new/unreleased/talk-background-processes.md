---
title: Talk's agent can keep a dev server running
kind: feature
area: app
---
In Talk, the agent can now start a dev server, a watcher or a long build in the background, read what it prints and stop it when done. Each one shows in the live process panel with its own Stop, gets the workspace's port, keeps running after a restart, and meets the same approvals as any command. Plan only starts none, and switching to Ask first or Plan only stops them.
