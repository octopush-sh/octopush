The Readiness card in Settings › General now lists every Claude Code fix you're missing, not only the newest. It names 2.1.331's fix for MCP calls that hang for up to 30 minutes, and 2.1.330's fix for lost settings saves, whenever a crew or Routine runs on Claude Code, not only while a Run session does.
