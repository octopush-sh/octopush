---
title: Comment on a plan inline before you approve it
kind: feature
area: app
highlight: true
---
When a Direct run stops at a gate, select a passage of the stage's output and use **Comment**
(or move over the passages with the arrow keys and press Enter) to add a note to it.
**Send back** and **Reject** send each quoted passage with your note, in document order.
**Approve with comments** passes them to the next stage as guidance for that pass.
