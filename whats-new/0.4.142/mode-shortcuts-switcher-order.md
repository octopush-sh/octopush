title: Mode shortcuts follow the switcher, left to right
kind: improvement
area: app
steps:
  - open: mode/run
    target: mode-switcher
    caption: Run is now ⌘⇧1 and Talk ⌘⇧2, the order they sit in. Review stays ⌘⇧3, Direct ⌘⇧D.
    action: none
  - open: settings/shortcuts
    target: settings-shortcuts-modes
    caption: Settings › Shortcuts lists the modes in that same order.
    action: none

The mode shortcuts now count left to right along the mode switcher: **⌘⇧1** is Run and
**⌘⇧2** is Talk (they were the other way around). Review stays ⌘⇧3, and Direct stays ⌘⇧D
because macOS keeps ⌘⇧4 for screenshots.
